# Quaternius Farm Buildings (CC0)

`Barn.obj`, `BigBarn.obj`, and `SmallBarn.obj` are Quaternius Farm Buildings models. The accompanying `LICENSE.txt` is the original CC0 1.0 license notice.

Source mirror used for these files: `Fialuxe/MouthOfGod_System`, pinned at commit `ffff299d6710f95016904f0b4beaedde65f38e42`, under `Assets/ArtisticResources/ThirdParty/Quaternius/Farm Buildings - Sept 2018/OBJ/`.

`tools/obj2glb.py` converts these models into `assets/models/buildings/`. The three barn variants replace the visible meshes on the map's enterable barn shells; their existing collision and interior layout are retained.
